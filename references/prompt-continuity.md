# First Person Continuity and Causal Locks

## 全局镜头

- 两条视频各自保持真实第一人称、单一连续长镜头。
- 驾驶时使用真实坐姿眼高；下车后和室内步行使用约 1.60 至 1.70 米成年人眼高。
- 镜头只随身体、载具、转头、行走、开门和互动移动。
- 禁止第三人称、无人机、独立运镜、机位重置、跳切、黑场、闪光、溶解、时间压缩和瞬移。
- 无对白、无人声、无旁白、无歌声、无背景音乐；只保留同步灾难声、空间环境声和动作声。

## 片段 A 不可逆因果链

```text
持续前进中的险情闪避
→ 不停车恢复方向
→ 取下固定原位的主题信标
→ 清楚展示
→ 沿唯一前进方向一次离手
→ 连续飞行
→ 同轴固定落点第一次落地
→ 同一点爆出巨大主题色雾墙
→ 保持前进并正面穿雾
→ 浓雾内庇护所始终不可见
→ 从远侧雾边穿出后第一次看见完整庇护所
→ 到门前停稳
→ 连续下车或脱离
→ 从真实落脚点走到门把
→ 开门进入空间 1
```

关键约束：

- 开场险情占满前 2 秒，危险物接近、最近点、撞击后果和恢复方向都可读，但不能遮满画面或让人物停下。
- 主题物在取用前已经存在且可达，不能凭空出现或主动飞到手中。
- 只允许一次投掷、一次落地、一次爆雾。离手后手臂立即收回，不做第二次挥臂。
- 投掷方向、物体轨迹、落点、雾墙中心、穿雾路线和庇护所入口位于同一连续轴线。
- 雾墙具有真实颗粒、体积光、风向剪切和沉降，不是纯色擦除或隐藏换景。
- 庇护所在穿过浓密核心之前完全不可见；出雾后直接以 F2 的完整稳定形态出现，不生长、不拼装、不变形。
- 入口在出雾后约 2 至 4 米，不能再跨越长道路或广场。
- 门从接近、停稳、下车、走近到开门始终连续可见。

## 片段 B 不可逆因果链

```text
走到互动 1 的自然触及距离
→ 停稳后互动
→ 可见反馈
→ 放回目标并松手
→ 收回手臂
→ 转身并走完整路径
→ 到真实门前停稳
→ 操作门把并打开门
→ 门框两侧空间短暂同框
→ 连续穿过门洞
→ 走到互动 2 的自然触及距离
→ 停稳后互动
→ 保持完成状态
```

关键约束：

- 所有目标和配套物从 F3/F4 起就在原位，不能在视频中凭空生成。
- 家具锁定世界坐标，不漂移、复制、消失或跟随镜头。
- 互动前必须靠近并停稳，不允许手臂异常伸长或隔空操作。
- 饮用或进食时，容器或食物越过画面上沿到视角外嘴边，再从同一位置返回。
- 触摸水面、床、沙发或宠物时，先用连续脚步证明到达自然前臂距离。
- 开门时旧空间、门框、门扇和新空间地面同时可读；禁止用门板全屏遮挡隐藏切镜。

## 关键帧连续检查

相邻图片同时满足：

- 连续项不变：人物身份、服装、灾难方向、主题色、建筑材质和主要地标。
- 推进项至少变化三项：相机位置、主体距离、背景视差、载具方向、身体姿势、手部状态或已完成动作。
- F1/F2 的道路、坡面、护栏或地面拓扑可由同一相机连续到达，固定地标左右顺序不颠倒。
- F3/F4 默认不露双手；确需露手时最多一只放松的手位于画面单侧下缘。
